# USB-Programming-Module-CH340C

This USB Programming Module CH340C is a compact USB to UART converter created for programming and debugging microcontrollers. It uses the CH340C chip, which provides serial communication between a computer and devices that operate with TTL level UART signals.

<img src="https://github.com/andreipopescufilimon/USB-Programming-Module-CH340C/blob/6fc07df5490c42b8e33dde423e5e1e665fc05040/media/pcb.jpeg" />

You can find the Gerber File and EasyEDA Project file on: [https://oshwlab.com/bicicleta11/usb-programming-module-ch340c](https://oshwlab.com/bicicleta11/usb-programming-module-ch340c)

## Key Features
- Built around the CH340C USB to UART controller  
- Supports USB 2.0 full speed communication  
- You need to install ch340c driver on your device
- RX and TX activity indicator LEDs  

## Pin Functions
Typical modules provide the following pins:
- **5V**: Power output, 5V  
- **GND**: Ground  
- **TXD**: Transmit data from the USB module to the target device  
- **RXD**: Receive data from the target device 
- **RST**: Reset signal for the target device. 

## Compatibility
The CH340C works with most popular development boards and operating systems including Windows, Linux, and macOS. Drivers are usually installed automatically or you can install them.
